# Ruined City

A side-scrolling zombie survival game that runs in the browser. Single HTML file, no dependencies.

**Controls**
- Desktop: A/D or arrow keys to move, W/Up/Space to jump, F/J/Enter to attack, G/K to shoot (once you have the gun)
- Mobile: on-screen buttons

**Worlds**
- World 1: Ruined City, Outskirts, Subway (boss: Zombie King)
- World 2: Military Base, Hospital, Warehouse (boss: The Survivor, reward: gun)

Progress and your custom character are saved in your browser.
